Context
Helix is a competitive ad-intelligence workstation. It has four loops: Discover (the only one built end to end), Intelligence (mine recurring creative patterns), Create (draft creative briefed on those patterns) and Performance (feed live results back into scoring).
Stack: Vite/React frontend on Vercel. FastAPI + async SQLAlchemy + Alembic on Neon Postgres. API and scrapling worker on Render.
It must support EN and AR (RTL), tenant isolation, and real AI results only.
There is NO billing provider: access is granted manually by an admin. Production currently shows a "Trial ended — select a plan" banner and a "Billing & Meter" page, which conflicts with that decision.
A Discover live search on production gets stuck at "resolving sources".
Sidebar: Discover, Intelligence, Create, Performance, Monitors, Scout, Swipe Files, Dashboard, Playbook & Guide, Docs & API Reference, Billing & Meter, Support & Feedback, Profile & Settings, Messages & Updates.
