## Tenant authorization exceptions

- `/api/brands/`, `/api/patterns/`: authenticated but global (F05).
- `/api/creatives/{id}/save`: existence check only (F03).
- `/api/playbooks` compilation: arbitrary job/global patterns/insights (F04).
- Insight generation and simulation: arbitrary creative IDs (F06).
- `/api/patterns/generate`: global fallback, shifted args and no spend gate (F53).
- Public updates/banner: visibility flag not applied (F48).
- Team invite redemption: identity not matched (F47); member org scope absent (F46).
- API keys: org principal discarded (F61).
- Admin data is intentionally cross-tenant, but granular permission flags are unused (F80).

Public sign-up/sign-in/reset, media catalogs, simulation segments, published playbooks, health/liveness and worker health are intentional public surfaces. Webhook, cron, worker heartbeat and local media enforce non-user boundaries in their handlers. Public playbook access itself is not an IDOR; the unauthorized source compilation is.
