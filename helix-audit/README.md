# How to use this kit

1. Extract this ZIP in the Antigravity workspace (outside tracked application code if preferred).
2. Give the agent access to the actual Helix repository and all files in this kit.
3. Paste the entire antigravity-helix-remediation-prompt.md into the agent, or ask it to read and execute that file in full.
4. Keep helix-audit/ available throughout implementation. Those files contain the complete audit and evidence.
5. The audit was made at fa8164920031a8dfaa036e2a67ee6f107a48a9f2. It is not proof of current/deployed state. The agent must reconcile current HEAD and revalidate fixes.

The prompt covers all 82 findings, nine implementation phases, mandatory behavior/concurrency tests, migrations, release safeguards and an 82-row closure report. No application fixes are included in this handoff kit.
