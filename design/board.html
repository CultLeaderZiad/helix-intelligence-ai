Before any design work: two open tails on merged PR #10

1 · Reset links are returned to the caller by default. backend/app/core/config.py → AUTH_DEV_RESET_RETURN: bool = os.getenv("AUTH_DEV_RESET_RETURN", "True"). If Render doesn't explicitly set it to false, POST /api/auth/forgot-password {"email":"any@user"} returns reset_url with a live token, and POST /api/auth/reset-password hands back a fresh session — i.e. takeover of any account, admin included. The reset flow itself is well built (hashed, single-use, purpose-claim, burned on bad guess); the default is the bug. Fix: default False, dev-only opt-in, and refuse to return the URL when settings.ENV == "production". There is also no rate limit on this endpoint.

2 · POST /api/auth/webhook accepts anyone. It computes the expected HMAC, logs both values, and never compares them — no dependency, no 401 — then creates users with a 14-day trial (vs 7 in signup) plus an org. Logging the expected signature also puts secret material in Render logs. Fix: compare with hmac.compare_digest, 401 on mismatch/absence, drop the log line, align trial length.

3 · GET /api/media/jobs/{job_id} has no ownership check. media_service.get_media_job selects by id alone while every other read in the app is scoped by user_id/org_id — so any signed-in user can read another user's prompt, result_url, error and parameters (incl. credential_mode). A job id is not a capability; filter by owner and 404 otherwise. (POST /media/jobs/{id}/cancel also reports success while nothing cancels the task.)

Spot-check of the rest of PR #10's claims against HEAD: import os added to groq + openrouter ✓ · heuristic synthesizer gone from ai/base.py ✓ (zero matches for "heuristic") · dedup partial unique index + IntegrityError race handling ✓ · startup sweep refunds stuck discover jobs ✓ · reset token single-use with hash-burn ✓. One perf note: get_password_hash is 100k-round PBKDF2 called synchronously inside async endpoints (sign-up, reset) — on Render's single worker that's a ~60–90ms event-loop stall per call; wrap in run_in_threadpool or move to argon2/bcrypt via the passlib you already ship.

Contract

  • Portalled fixed stack, bottom-right, role="status" / aria-live="polite", stacked max 3, dismiss on click, ⌘/Ctrl+D clears

  • Acceptance: no state-changing action in the app completes without one visible confirmation; error toast text is never a raw exception string
